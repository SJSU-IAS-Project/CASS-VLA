# Literature and State-of-the-Art Survey

## Research area

This project studies runtime safety verification for Vision-Language-Action driving planners. The focus is not on training a driving model from scratch. Instead, we investigate whether a VLA-based supervisor can evaluate a candidate trajectory, selectively gather additional visual evidence, and intervene only when calibrated risk is high.

## SOTA observations

Recent work establishes several important capabilities:

1. VLA models can generate interpretable reasoning traces and driving actions.
2. Counterfactual reasoning can improve planning by allowing the model to revise unsafe behavior before execution.
3. VLA critics can score and refine candidate trajectories.
4. Active perception tools such as region inspection, depth estimation, and object detection can resolve ambiguous visual evidence.
5. Sensor degradation and long-tail hazards can cause reasoning instability and dangerous planning errors.
6. Risk calibration and conformal prediction are promising ways to quantify uncertainty, but they are not yet well integrated with tool-using VLA driving supervisors.

## Gap addressed by this project

Existing systems mostly answer one of the following questions:

- Can a VLA produce a better trajectory?
- Can a VLA reflect on a trajectory?
- Can a VLA call a visual tool under uncertainty?
- Can an LLM planner receive calibrated safety feedback?

CASS-VLA combines these into a runtime-assurance question:

> Given a candidate trajectory from a main planner, can a VLA supervisor decide whether the evidence is sufficient to accept it, whether a particular visual tool should be called, or whether the plan must be rejected?

## Relevance to the proposed method

CASS-VLA will build on prior work while targeting the unaddressed intersection of:

- trajectory-conditioned safety judgment;
- calibrated uncertainty estimation;
- selective active perception;
- runtime acceptance, veto, replanning, and fallback;
- explicit safety-versus-compute tradeoff analysis.

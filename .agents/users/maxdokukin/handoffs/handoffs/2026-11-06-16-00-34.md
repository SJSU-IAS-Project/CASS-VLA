## 6. Design decisions

- **Decision:** Scale every family's speed and acceleration ranges by 0.8 when fixing the substep bug.
  **Why:** The validated scenarios were tuned with vehicles at 0.8 of their commanded speed. Unscaled, the lead in `lead_brake_cutin` is as fast as the ego and no hazard happens.
  **Alternatives rejected:** Re-tuning every family by hand, which would take longer and invite tuning on test data.
- **Decision:** Leave the windows unchanged although validation coverage is 87.5% on `occluded_cross_traffic` and 93.2% on `ambiguous_light`.
  **Why:** The window rule forbids changing windows after validation.
  **Alternatives rejected:** Widening those two windows.
- **Decision:** Fix the MLP settings (32 hidden units, 300 Adam steps, lr 0.01, l2 1e-3) before any evaluation, and never tune them.
  **Why:** Tuning on the splits would need fresh test seeds.
  **Alternatives rejected:** A hyperparameter search on validation.
- **Decision:** Use the final split (seeds 400-459) a second time, for the pre-registered data-size check.
  **Why:** The check was written down before its data existed, and it changes no method choice. The seeds are now marked as seen in `SEEDS.md`.
  **Alternatives rejected:** Running the check on val and test only.
- **Decision:** Make expected-gain targets the default for the next run, and measure against the fair ceiling rather than the oracle selector.
  **Why:** The pre-registered decision rule was met in all 6 cells, and the oracle selector's lead is mostly noise luck that no selector can foresee.
  **Alternatives rejected:** Keeping single-draw targets.
- **Decision:** Launch no subagents and run no git writes.
  **Why:** The user's standing rules require approval for subagents and forbid git writes.
  **Alternatives rejected:** none

## 7. Philosophical choices

- Write the question and the decision rule into the analysis script before its data exists, and report the result whichever way it falls.
- Judge a selector against what can be known at decision time, not against an oracle that sees the noise.
